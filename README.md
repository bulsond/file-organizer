# file-organizer
Учебный проект с [сайта](https://praxiscode.io/)

## File Organizer

### 📋 Описание проекта
Основанный на Go инструмент сортировки файлов по директориям в зависимости от их типа.

### 🛠 Основные функции

- Получение от пользователя целевого директория для сортировки файлов
- Создание поддиректорий и перемещение файлов в зависимости от их расширения
- Создание и отображение отчета о выполненной сортировки

### 🚀 Установка и запуск

1. Клонируйте репозиторий
   ```bash
   git clone https://github.com/bulsond/file-organizer.git
   ```
2. Перейдите в директорию проекта
   ```bash
   cd file-organizer
   ```
3. Запустите программу
   ```bash
   go run .
   ```

### 🔍 🧪 Тестирование работы приложения

1. Убедитесь, что скрипт имеет права на выполнение: `chmod +x generate_test_files.sh`
2. Запустите скрипт: `./generate_test_files.sh`
3. Скрипт создаст директорию `generated_files` и наполнит её 100 случайными файлами
4. Запустите ваш файловый органайзер на этой директории для проверки работы
